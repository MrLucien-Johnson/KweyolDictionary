# Pronunciation audio

Drop verified or provisional recordings here using this file name:

```text
{entry-slug}.mp3
```

Examples:

- `bonjou.mp3`
- `li-read.mp3`
- `jwe-play.mp3`

## Rules

1. Prefer clear Dominican Kwéyòl speakers.
2. After adding files, run `npm run content:publish` so the catalog picks them up.
3. Published audio starts as **PLACEHOLDER** until a reviewer confirms native pronunciation.
4. Do **not** claim browser speech synthesis as native audio.

Featured words are the first recording priority.
