# Dominican Kwéyòl–English Dictionary Project

Learn, preserve and celebrate the Kwéyòl language of Dominica.

This repository will host an adult Kwéyòl–English dictionary and a separate child-friendly learning dictionary. Content is limited to **Dominica’s Kwéyòl** variant.

## Language policy

Do not mix Dominican Kwéyòl with Haitian Creole, Saint Lucian Kwéyòl, Guadeloupean Creole, Martinican Creole, or other Creole variants unless a word is clearly labelled as a regional comparison and approved for inclusion.
