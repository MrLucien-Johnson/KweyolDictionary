# Dominica-only Kwéyòl language policy

This project documents and teaches **Dominica’s Kwéyòl** only.

## Do

- Prefer vocabulary, examples and audio verified for Dominican usage
- Mark every entry with a review status
- Keep unverified or demonstration content as `DRAFT` or `NEEDS_REVIEW`
- Label regional comparisons clearly when they are intentionally included

## Do not

- Silently copy vocabulary from Haitian Creole, Saint Lucian Kwéyòl, Guadeloupean Creole, Martinican Creole or other Creole variants
- Invent translations and present them as approved
- Publish draft demonstration seeds to the public dictionary

## Review statuses

| Status | Meaning |
|--------|---------|
| `DRAFT` | Working content; not public |
| `NEEDS_REVIEW` | Submitted for language review |
| `LINGUIST_REVIEWED` | Checked by a language reviewer |
| `COMMUNITY_REVIEWED` | Checked by community reviewers |
| `APPROVED` | Safe for public display |
| `REJECTED` | Not accepted |
| `ARCHIVED` | Removed from active use |

Public users should normally see **approved** entries only.

## Editorial note for learners

Dominican Kwéyòl varies by community, generation, speaker and context. Spellings and everyday usage can differ. This platform aims to treat the language with care and cultural respect.
